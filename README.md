# QT-Wafer-Map

基于 Qt/C++ 的晶圆图（Wafer Map）查看、编辑与路径规划工具。它可以读取常见的文本、Map、CSV 和 Excel 晶圆图数据，并以大图与局部小图联动的方式展示 bin 分布、坐标和加工状态，适合用于晶圆图分析、点位确认和蛇形走位验证。

![QT-Wafer-Map 主界面](chip.png)

## 功能特性

- **多格式加载**：支持普通文本/`.map`、`.csv`、`.xlsx`、`.xlsm` 和 `.xltx` 文件。
- **灵活的数据范围配置**：
  - 默认加载文本或 Map 地图。
  - 自定义文本地图的起止行、起止列和 bin 值位数。
  - CSV 文件配置数据起始行以及 X、Y、bin 所在列。
  - Excel 文件选择工作表索引和单元格范围。
- **地图可视化**：大图与局部小图同步显示，支持鼠标滚轮缩放、拖拽平移、坐标刻度和当前点定位。
- **方向与旋转**：支持 0°、90°、180°、270° 旋转，以及 8 种蛇形行进方向。
- **bin 统计**：按 bin 显示颜色、总数量、加工数量和剩余数量，可勾选需要参与路径规划的 bin。
- **对点与寻起点**：设置起点、参考点和多个验证点，生成并逐步执行寻起点路线。
- **路径规划**：根据选中的目标 bin 自动规划蛇形加工路径，支持借助路径和定时步进显示。
- **地图编辑**：支持点选、框选和圆选，可批量修改选区 bin 值或裁剪选区。
- **扫码查找**：输入扫描内容后，在指定目录或磁盘范围内查找匹配的地图文件并加载。

## 环境要求

- Windows
- Qt 5.x 与 Qt Creator
- qmake 构建工具
- 支持 C++11 的编译器（项目默认按 MSVC 配置）

项目使用了 Qt 的私有头文件 `QtGui/private/qzipreader_p.h` 来解析 Excel Open XML 文件。编译时需要安装与当前 Qt 版本匹配的 Qt GUI 私有开发文件。

## 构建运行

### 使用 Qt Creator

1. 克隆仓库并打开 `MapTest/MapTest.pro`。
2. 选择可用的 Qt Kit 和编译器。
3. 配置、构建并运行项目。

### 使用 qmake

```powershell
git clone https://github.com/735754647/QT-Wafer-Map.git
cd QT-Wafer-Map\MapTest
```

然后在 `MapTest` 目录执行：

```powershell
qmake MapTest.pro
nmake
```

如果使用 MinGW，可将最后一步替换为：

```powershell
mingw32-make
```

项目当前提供 qmake 工程，未提供 CMake 配置。

## 使用说明

1. 启动程序后，在右侧功能区选择地图加载方式。
2. 点击“加载文档”选择地图文件；CSV、文本自定义加载和 Excel 加载会弹出对应的范围或列配置窗口。
3. 在 bin 表格中查看各类 bin 的颜色和数量，并勾选需要参与加工的目标 bin。
4. 在“Map 地图对点”中设置行进方向、起点、参考点和验证点。需要自动寻找起点时，先点击“寻起点”。
5. 在“Map 路径规划”中点击“开始规划”，程序会按选定方向逐格执行路径规划；再次点击可停止运行。
6. 在“Map 编辑”中选择点选、框选或圆选模式，然后修改选区 bin 值或裁剪选区。

大图支持滚轮缩放和鼠标拖拽平移；“恢复视图”可以恢复默认缩放状态。“手动扫码”支持按输入内容在指定目录或磁盘中搜索地图文件。

## 支持的数据

仓库中的 `地图文件/` 目录包含多种文本、Map、CSV 和 Excel 示例，可用于验证加载逻辑。不同厂商的地图文件布局可能不同，加载时请根据文件实际结构配置行列范围、bin 位数或 CSV 列映射。

当前 Excel 解析针对 Office Open XML 格式，支持 `.xlsx`、`.xlsm` 和 `.xltx`，不包含旧版二进制 `.xls` 文件解析。
